An end-to-end quantitative machine learning pipeline designed to predict stock price movements, forecast closing trends, and evaluate trading signals using deep learning (LSTM/GRU) and technical indicators.

🔗 Live Demo: https://stock-insight-twbm8ovxnxbxibgfxl8oqr.streamlit.app/

✨ Features📊 Live Market Data: Fetches real-time and historical stock data using yfinance or Alpha Vantage.📈 Technical Indicator Suite: Calculates RSI, MACD, Bollinger Bands, Moving Averages (SMA-200, EMA-50), and daily returns.🧠 Deep Learning Models: Trains LSTM (Long Short-Term Memory) and GRU architectures to capture time-series sequential patterns.🎯 Backtesting Engine: Simulates trade signals (Buy/Sell/Hold) based on forecast confidence and directional accuracy.📱 Interactive Dashboard: Streamlit web interface for searching tickers, adjusting lookback windows, and plotting future price targets.
