# 📈 Stock Analytics & Prediction App

An interactive web application built with **Streamlit** and **Python** that allows users to analyze historical stock data and view market predictions.

## ✨ Features
* **Interactive UI:** Dynamic charts and market visualization using Streamlit.
* **Data Integration:** Built-in SQLite database support (`stocks.db`).
* **Live Deployment:** Hosted on Streamlit Community Cloud.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit
* **Data & Analytics:** Python, Pandas, SQLite
* **Deployment:** Streamlit Cloud / GitHub
